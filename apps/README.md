# apps

Client surfaces / experience layer. Regional UI, localisation, accessibility and feature flags. No client-side balance authority.

**SRS:** SRS-316-AFR-001 §2, §3

## Requirement IDs

- `NFR-08` — Accessibility: WCAG 2.2 AA target for applicable app/web flows
- `NFR-09` — Localization: Country language/currency/phone/date and low-bandwidth support
