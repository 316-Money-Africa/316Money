What is Request Money?

Request Money lets you ask friends, family or other eligible recipients to pay you, and keeps track of each request in the app.

Can I add a reason to my request?

Yes. You can add a short note so the person knows what the request is for.

Can I set an expiry date?

Yes. You can choose when a request expires, and you can send a reminder before then.

What happens if someone declines a request?

The request is marked as declined in your activity and no money moves.

How do I know if someone has paid?

The request status changes to paid and you receive a notification.

Can someone pay only part of their share?

Yes, where partial payments are enabled. Each payment is tracked against the original request.
