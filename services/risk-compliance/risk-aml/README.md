# risk-aml

Rules, velocity limits, holds, anomaly detection, anti-collusion checks and AML case management.

**SRS:** SRS-316-AFR-001 §4, §16

## Requirement IDs

- `SEC-002` — Financially sensitive operations SHALL use MFA/step-up verification, velocity limits and anomaly detection.
- `SEC-005` — Compliance controls SHALL support KYC/KYB, sanctions/PEP screening, AML monitoring and case management.
- `SEC-006` — Agent cash workflows SHALL use anti-collusion controls, transaction limits, unique challenges and fraud investigation capability.
- `ADM-003` — Compliance users SHALL review KYC/KYB, agent approval, suspicious activity and restrictions.
