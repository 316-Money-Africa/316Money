# refund-dispute

Refunds, reversals, claims, chargebacks and evidence.

**SRS:** SRS-316-AFR-001 §4, §7

## Requirement IDs

- `PAY-010` — Refunds SHALL enforce role permissions, provider eligibility, balance availability and approval policy.
- `MON-EXT-002` — Reloadly gift-card/airtime orders SHALL maintain fulfilment state, provider reference, delivery details and dispute/refund exceptions.
