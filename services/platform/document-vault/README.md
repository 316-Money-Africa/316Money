# document-vault

Statements, receipts, agent contracts, certificates and compliance documentation.

**SRS:** SRS-316-AFR-001 §4, §8.1

## Requirement IDs

- `HOT-REG-007` — Agents SHALL access a document centre for contracts, statements, certificates, notices and compliance requests.
- `MON-004` — Users SHALL view available, pending and reserved funds, statements, fees and transaction details.
