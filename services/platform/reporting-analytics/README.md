# reporting-analytics

Consumer, merchant, agent and admin insights built from eventually consistent read models.

**SRS:** SRS-316-AFR-001 §4

## Requirement IDs

- `PAY-003` — Merchant dashboard SHALL show payment volume, success rates, fees, refunds, unsettled amounts and settlements.
- `HOT-OPS-004` — Agent analytics SHALL include cash-in/out volume, completion rate, fees, repeat customers, disputes and trends.
- `ADM-007` — Dashboards SHALL distinguish actual settled revenue from pending gross payment volume.
