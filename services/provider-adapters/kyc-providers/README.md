# kyc-providers

KYC/KYB and screening provider adapters.

**SRS:** SRS-316-AFR-001 §14

## Requirement IDs

- `INT-001` — Each provider adapter SHALL declare supported countries, currencies, methods, limits, refund capabilities and callback semantics.
- `SEC-005` — Compliance controls SHALL support KYC/KYB, sanctions/PEP screening, AML monitoring and case management.
